The safety warning label that should come printed on every human being:
this one operates on caffeine, spite, and sleep it never got. Do not
shake it. Do not ask how it is doing before coffee. An entry for the
make.fun bounty
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

Why this label works: every line of it is recognisable from real life —
the fuel list is honest, the handling instructions are the ones people
actually need, and the last clause is the hazard warning that matters
most, printed where nobody can miss it.

## Run it

```sh
python3 main.py
```

This writes the one-line warning label to `entry.txt` (and to
`/output/entry.txt` when the grading sandbox provides `/output`).
